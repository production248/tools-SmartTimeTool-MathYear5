# Smart Time Tool - Math Year 5

Independent Math Year 5 edition generated from the shared Smart Time Tool source.

- Fixed curriculum level: Math Year 5
- Activities: limited to the existing textbook-aligned d5 configuration
- Languages: Bahasa Melayu, Chinese, and English
- Input: mouse, touch, and keyboard friendly
- Teacher controls: custom questions within the existing year-specific limits

The year selector is intentionally hidden in this edition. Shared interface and interaction
changes should be made in the source project and exported again so all editions stay consistent.
